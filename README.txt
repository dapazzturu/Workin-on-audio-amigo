BEYOND THE EVENT HORIZON
1. Extract the ZIP while preserving the css/, js/ and assets/ folders.
2. Open index.html in a modern browser (or host the folder on any static web host).
3. Press LET'S BEGIN to start.
4. Background music: place your track at assets/audio/ambient.mp3 (this file is NOT included).
   Sound effects live in assets/audio/SFX/ (folder name is case-sensitive on web hosts).
   Paths are set in js/config.js (musicPath, sfxPath).
5. Edit js/config.js to customize constellation messages, loading facts and descent duration.
6. Edit the letter text directly in index.html (<article id="letterContent">).
No build tools or server are required. Google Fonts are loaded online; system fallbacks remain available offline.
See PROJECT_HANDOFF.md for the current project state.
